# Telegram User Datails API

### Install Required Libraries
```bash
pnpm install
```

### Run the Server
```bash
pnpm start
```

### Run the Server with hot reload
```bash
pnpm dev
```

### If you want to use it inside a Serverless Functions
```bash
pnpm serverless
```


# Example

### Request
```
http://localhost:4567/taraknath341
```
